# GĐ0 — Nền móng (DB + tài khoản khách + đồng bộ) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Người học có tài khoản thật (khách + mã khôi phục), dữ liệu học lưu trên server qua hàng đợi local-first, bản release không còn 401, xóa tài khoản xóa thật.

**Architecture:** Schema Drizzle ở `packages/contracts/src/db/schema.ts` (một nguồn), migration SQL đánh số trong `apps/gateway/drizzle/`, Gateway mở DB lười (`DATABASE_URL` → postgres-js, không có → PGlite; test dùng `memory://`). Auth: access JWT 15 phút + refresh token mờ (lưu băm, xoay vòng) + mã khôi phục (lưu băm). Client: phiên khách lười trong `@vietlearning/api-client/session`, outbox so sánh store với “bóng” (shadow) trong `@vietlearning/state/sync`; cả hai import lười từ Host để không vượt ngân sách bundle đầu 68 kB.

**Tech Stack:** Fastify 4, drizzle-orm 0.39.3, drizzle-kit 0.30.6, @electric-sql/pglite 0.5, postgres 3.4, @fastify/jwt, Zod 3, Zustand 5, @capacitor/preferences 7, node:test, vitest, Playwright.

**Spec:** `docs/KE_HOACH_PHAT_TRIEN_TOAN_DIEN.md` mục 0, 2, 4 (R2, R3, R4, R7, R8, R13), 5 (GĐ0), 9 + brief của phiên điều phối (phạm vi 1–7).

## Global Constraints

- Contract trước: mọi request/response mới có Zod schema trong `packages/contracts/src/api/` và Gateway trả qua `respond()`.
- Không secret ở client; khóa Gemini chỉ ở `%USERPROFILE%\.becutit\gateway.env`, không commit.
- Mọi chuỗi UI có `vi` + `en` qua `i18n.ts` của MFE; nội dung học giữ tiếng Việt.
- Không sửa: `apps/host-shell/src/screens/Home.tsx`, `apps/host-shell/src/routes.tsx`, `packages/content/src/data/course/`, `packages/exercises`, `apps/mfe-path`. `packages/state/src/index.ts` chỉ sửa tối thiểu (tốt nhất: không sửa).
- Không import chéo MFE (`pnpm lint:boundaries`); `@vietlearning/state/sync` KHÔNG re-export từ `index.ts`.
- Bundle đầu ≤ 68 kB gzip (`pnpm --filter @vietlearning/host-shell size`).
- Chỉ tắt PID mình mở. Nhật ký ở `docs/nhat-ky/GD0.md` (không sửa `docs/NHAT_KY_CHUYEN_DOI_MOBILE.md`).
- `daily_activity.day` = ngày địa phương `YYYY-MM-DD` client gửi, server không tự tính theo UTC.
- Hằng số: access token 900 s; refresh token 90 ngày; mã khôi phục 16 ký tự Crockford base32 (80 bit) hiển thị `XXXX-XXXX-XXXX-XXXX`; lô sync ≤ 200 sự kiện; attempts trong snapshot ≤ 1000.
